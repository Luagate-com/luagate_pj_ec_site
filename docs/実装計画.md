# 実装計画（画面・機能単位）

## 目的
`docs/` 配下の設計資料（特に `docs/詳細設計書.md`）に基づき、画面/機能単位で実装計画と想定工数（人日）を整理する。

## 前提
- 技術スタック: Java 17 / Servlet / JSP / MySQL
- 画面・URL・処理フローは `docs/詳細設計書.md` に準拠
- 商品/在庫の初期データ（seed）は投入済み
- JSPは描画専用（業務判断・DBアクセスは行わない）
- カートはセッション保持（session.cart）
- 注文確定はトランザクション境界で実行
- 全画面レスポンシブ対応（PC/スマートフォン/タブレット）

## 工数の見積り条件
- 単位: 人日（1人日 = 7.5時間）
- 画面/機能ごとに「Servlet + JSP + DAO/Service/バリデーション」を含む
- UI/デザインの高度表現は対象外
- パフォーマンスチューニング・本番運用設計は対象外

## 共通基盤（全画面共通）
**内容**
- ディレクトリ構成の作成（controller / service / dao / dto / util / webapp）
- DB接続/トランザクションユーティリティ
- 共通バリデーション基盤
- 共通エラー画面（404/500）

**工数**
- 1.5人日
