# デザインまとめ（Figma: 商品一覧 FR-01）

## 対象
- 画面: 商品一覧（FR-01）
- Figma node-id: 1:102

## 全体トーン
- ベースはアイボリー寄りのオフホワイト（背景・カードともに同系色）
- 境界線とタイポグラフィのコントラストを抑えた、落ち着いた雑貨店らしいトーン
- アクティブ要素のみグリーンで強調

## レイアウト
- ヘッダー高さ: 72px
- コンテンツ領域: 横方向に広めの余白（左右 200px）、縦方向に 64px の余白
- 商品カードは 3 列グリッド、カード間ギャップ 16px
- 商品画像エリア高さ: 160px
- ページャは下部中央に配置

## カラー
- 背景: #FDFDFA
- カード背景: #FDFDFA
- ボーダー（メイン）: #DCDCD9
- サブ背景（タブ背景）: #F5F4ED
- タブ選択背景: #E8E7E2
- 主要テキスト: #363635
- サブテキスト: #727270
- プレースホルダー: #A2A29F
- アクセント（アクティブ/強調）: #037F40

## タイポグラフィ
- 日本語本文/見出し: Noto Sans CJK JP
- 英数字/価格: Inter
- 見出し（商品セクション）: 18px / SemiBold
- サブ情報（件数・カテゴリ）: 13px / Regular
- 商品名: 16px / SemiBold
- 価格: 14px / Regular

## コンポーネント構成

### ヘッダー
- 左: ロゴ + タブ（新着 / カテゴリ / ギフト）
- 右: 検索入力、ログインボタン、カートアイコン
- 検索入力
- 高さ 40px、角丸 8px、左右パディング 16px
- ログインボタン
- 高さ 40px、角丸 8px、ボーダー #DCDCD9

### カテゴリタブ（商品一覧内）
- タブコンテナ: 角丸 12px、背景 #F5F4ED
- タブ（選択）: 背景 #E8E7E2、文字色 #727270
- タブ（非選択）: 文字色 #727270
- タブラベル: 12px
- 表示例: すべて / キッチン / 文具 / インテリア / ギフト

### 商品カード
- 角丸 16px、ボーダー #DCDCD9
- 画像エリア: 160px、高さ固定、object-fit: cover
- 本文エリア: パディング 16px、縦間隔 6px
- 表示項目: 商品名 / カテゴリ / 価格

### ページャ
- 左右矢印のアイコンボタン（40px 角、角丸 8px）
- 中央に「01 / 06」表記
- アクティブ番号はアクセントカラー

## 画面内の文言（抜粋）
